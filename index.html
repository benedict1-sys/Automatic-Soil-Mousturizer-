Automatic Soil Moisture Sprinkler System

Smart irrigation project report using Arduino and soil moisture sensing

1. Introduction

The Automatic Soil Moisture Sprinkler System is an Arduino-based project designed to monitor soil moisture levels and automatically control a watering system. The main purpose of this project is to reduce manual watering, save water, and provide plants with the appropriate amount of moisture.

The system uses soil moisture sensors to measure the moisture content of the soil. An Arduino Uno processes the sensor readings and determines whether watering is required. An LCD display shows the sensor values and their ON/OFF status.

The project is developed and tested using the Wokwi online simulation platform.

2. Objectives

  • To develop an automatic plant watering system.
  • To monitor soil moisture levels using sensors.
  • To control watering based on a predefined moisture threshold.
  • To display sensor readings on an LCD screen.
  • To reduce water waste and human effort.
  • To demonstrate the practical application of Arduino in smart agriculture.

4. Working Principle

The system operates using four analog sensor inputs connected to Arduino pins A0, A1, A2, and A3.

First, the moisture sensors measure the moisture levels in the soil and send analog signals to the Arduino.

The Arduino compares each sensor reading with a predefined threshold value of 500.

  • If the sensor reading is below 500, the system identifies the condition as requiring watering and activates the corresponding digital output.
  • If the sensor reading is equal to or above 500, the corresponding output remains OFF.

The system displays the sensor readings and their ON/OFF conditions on the LCD screen.

This process is repeated continuously, allowing the system to monitor soil moisture in real time.

5. Circuit Description

The circuit is designed using an Arduino Uno as its central processing unit.

The four moisture sensor signals are connected to analog input pins A0, A1, A2, and A3. Four digital output pins (8, 9, 10, and 11) are configured to control the corresponding outputs.

An I2C LCD module is connected to the Arduino to display the sensor readings. The LCD uses the I2C address 0x27 and has 16 columns and 2 rows.

An LED with a current-limiting resistor is also included in the circuit to provide a visual indication.

All components are connected according to the circuit diagram in the Wokwi simulation.

6. Software Implementation

The project is programmed using Arduino C/C++.

The program uses the following libraries:

  • Wire.h
  • LiquidCrystal_I2C.h

The LCD is initialized using the I2C address 0x27.

The four sensor values are read using the analogRead() function. The digitalWrite() function controls the output pins according to the threshold condition.

Threshold: threshold = 500
  1. Reads the four analog sensor values.
  2. Compares each value with the threshold.
  3. Activates or deactivates the corresponding digital outputs.
  4. Displays sensor readings on the LCD.
  5. Repeats the process continuously.
